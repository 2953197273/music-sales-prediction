# music‑sales‑prediction
# 基于用户行为数据的音乐流行趋势预测

## 项目简介
基于音乐用户行为数据集，完成数据清洗、探索性分析与特征工程，构建机器学习回归模型，预测音乐流行热度，挖掘用户行为、歌曲属性对音乐流行趋势的影响。

**技术栈**：Python、Pandas、NumPy、Matplotlib、Seaborn、Scikit‑learn

### 数据集说明
原始用户行为数据集文件体积较大，未上传仓库，本地运行请自行下载数据集放置对应路径。

## 项目主要工作
1. 数据预处理：缺失值、异常值处理，类别特征编码
2. 探索性数据分析：分析发布年份、用户播放行为与歌曲热度之间的趋势关系
3. 特征工程：筛选有效特征，划分训练集、测试集
4. 训练回归模型，完成参数调优
5. 模型评估：MAE、MSE、R²指标评估，输出特征重要性，分析影响音乐流行度的关键因素
6. 输出业务分析结论，给音乐运营提供参考建议

## 运行环境
Python >=3.9
依赖：pandas, numpy, matplotlib, seaborn, scikit‑learn
